# Timers

Mode: Operate. Audience: MLS/MLT techs and students at the microscope, starting concurrent stain and wait clocks with one hand.

Task: create labeled countdowns, run several at once, add time without stopping, tell running / paused / done at a glance, hear a chime when one ends (mute available). Persist in this browser.

Constraints: inherit Skiptocyte stain-wash blues, IBM Plex, pill radius, offline localStorage. No patient data. Google Search timer grammar, not a new identity.

## Direction contract

THESIS: Concurrent labeled stain-wait rings, not a single kitchen clock. Refuses one hero timer plus a stacked list of leftover chips.

OWN-WORLD: Skiptocyte wash; running cards sit in primary-tinted paper with a thin remainder arc; paused desaturates to slate-ochre; done floods teal-green and pulses. IBM Plex tabular digits, Google-like pills, title as a quiet field on the ring.

STORY: A tech names a wait, starts it, starts another, adds thirty seconds while looking at the scope, and knows from color which one is ringing.

FIRST VIEWPORT: Heading and mute. Composer: note field, large mm:ss, stain presets, Start. Below, a wrapping grid of rings — time inside, +0:30 / +1:00 / +5:00, pause and reset. Empty: composer only, copy that several waits can run at once.

FORM: Google Search timer structure inside Skiptocyte tokens. Signature interaction: the card hue shift plus the remainder arc. Seed: specified-direct (user-pinned Google timer; no concept-seed).

FINISH: unreviewed and undocumented is unfinished; this build ends with the finish review, the verdict, DESIGN.md, and every shipping raster carrying its provenance
