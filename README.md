# Skiptocyte 3.0

React rewrite of the WBC differential counter. Offline-first bench tool.

## Scripts

```
npm install
npm run dev
npm test
npm run build
```

Copy `.env.example` to `.env` and fill in your Firebase / FormSubmit values.

Firebase Hosting serves `dist/` with SPA rewrites. Auth/Firestore emulators: 9099 / 8080.
